# Weather Website 🌦️

A simple, clean, and user-friendly weather website built using **HTML and CSS**.  
The website provides a minimal interface where users can enter a city name and view weather information such as temperature, humidity, and wind speed.

## ✨ Features

- Clean and minimal user interface
- City-based weather search interface
- Displays temperature and city name
- Shows humidity information
- Shows wind speed
- Weather-condition illustrations
- Responsive and visually appealing layout

## 🛠️ Technologies Used

- **HTML5** – Structure and content of the website
- **CSS3** – Styling, layout, colors, gradients, and visual design

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `main.html` in any modern web browser.
4. Enter a city name to explore the website interface.

## 🎯 Project Objective

The objective of this project is to create a simple and clean weather website interface using fundamental front-end technologies and to practice HTML structure, CSS styling, layout design, and user-interface development.
